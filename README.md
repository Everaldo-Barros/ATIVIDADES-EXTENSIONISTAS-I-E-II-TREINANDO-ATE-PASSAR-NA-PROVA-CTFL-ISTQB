# ATIVIDADES-EXTENSIONISTAS-I E II---TREINANDO-AT-PASSAR-NA-PROVA-CTFL-ISTQB
Este repositório é exclusivamente reservado para o desenvolvimento das Atividades Extensionistas I e II, do Centro Universitário Internacional UNINTER – Escola Superior Politécnica – ESP

## CTFL Quest

Aplicação web interativa de apoio ao estudo da certificação CTFL ISTQB Foundation Level. O banco atual contém 120 questões em seis módulos; cada questão apresenta cinco alternativas e uma única resposta correta.

### Funcionalidades

- Seis módulos temáticos baseados nos tópicos do syllabus;
- Questões com feedback imediato;
- Simulados com 40 questões escolhidas aleatoriamente e duração de 60 minutos;
- Nota de aprovação do simulado alinhada ao exame CTFL: 26 de 40 acertos;
- Embaralhamento das questões e das cinco alternativas, mantendo a resposta correta vinculada ao texto;
- Evita repetir o mesmo conjunto de 40 questões em simulados consecutivos;
- Acompanhamento de progresso local;
- Certificado simbólico para aproveitamento igual ou superior a 90% na avaliação;
- links para fontes oficiais do ISTQB.

Os PDFs anexados foram verificados: o arquivo de planejamento é um modelo em branco e o relatório não contém conteúdo de aulas nem questões. O banco contém questões e explicações originais baseadas no **ISTQB CTFL Syllabus v4.0.1**, referência citada no relatório. Atribuição: International Software Testing Qualifications Board (ISTQB), *Certified Tester Foundation Level Syllabus v4.0.1*, [página oficial](https://istqb.org/certifications/certified-tester-foundation-level-ctfl-v4-0/), licença [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). O curso da Udemy não foi usado como fonte direta, pois seu material não foi fornecido. O capítulo de referência é exibido no feedback de cada resposta.

### Executar localmente

Abra o arquivo `index.html` diretamente no navegador ou utilize um servidor estático:

```powershell
python -m http.server 8080
```

Depois acesse `http://localhost:8080`.
